# Security Policy

## Reporting a vulnerability

Please report security issues privately, not in a public issue or pull request.

Use GitHub's private vulnerability reporting: open the repository's **Security** tab and click **Report a vulnerability**. Include what you found, how to reproduce it, and what it could expose (for example, someone else's match, email address or reveal link).

You'll get a reply there. Please give it a reasonable time to be fixed before sharing details publicly.

## Supported versions

Only the live app and the `main` branch are supported; fixes are deployed from `main`.
